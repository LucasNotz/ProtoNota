Funcionalidades

O que o ProtoNota oferece

Desenvolvido com foco em armazenamento local seguro para registros financeiros pessoais.

Hash de Senha

Suas credenciais de login são armazenadas utilizando técnicas de hashing, garantindo que a senha nunca seja salva em texto plano.

SHA-256

Criptografia de Dados

Informações sensíveis das notas fiscais são armazenadas de forma criptografada, protegendo seus dados financeiros em repouso.

Armazenamento Local

Consulta de CEP

Ao visualizar seus arquivos, verifique facilmente informações completas de endereço a partir de qualquer CEP brasileiro diretamente no app.

ViaCEP integrado

Considerações Importantes

  • Este projeto está em fase de desenvolvimento — não recomendado para produção.
  • Os mecanismos de segurança não foram totalmente testados ou auditados.
  • Projetado exclusivamente para sistemas Linux.
  • O uso é por conta e risco do usuário.
Requisitos
Java SE-21 Linux (x86_64) Arquivo .jar executável

Como Executar

Comece em 3 passos

protonota — guia de instalação
01

Instale o Java. Certifique-se de ter o Java SE-21 instalado no seu sistema Linux. Verifique com java --version no terminal.

02

Torne o .jar executável. Navegue até a pasta do projeto e execute chmod +x ProtoNota.jar para conceder permissão de execução.

03

Execute o aplicativo. Dê um duplo clique no .jar ou rode java -jar ProtoNota.jar pelo terminal. O app abrirá na tela de login.
